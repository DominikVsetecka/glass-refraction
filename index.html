How it works

A fixed strip at the top of the page uses backdrop-filter: url(#filter). The SVG filter moves every pixel with feDisplacementMap, guided by a few greyscale images drawn once in a canvas. Mid-grey means "stay", lighter and darker push the pixel up or down.

One map stretches vertically (the lens), one spreads sideways (the fan). The vertical pass runs five times, tinted red, yellow, green, cyan and blue. Where they overlap, they add up to white, so only the edges show colour.

Why grey maps

Chrome converts filter images into the colour profile of each screen. A colourful map mixes its channels in that step, so the band tilts differently on every monitor. Grey stays grey everywhere. The second axis reads the alpha channel, and a counter-pass cancels whatever is left.

Browser support

SVG filters inside backdrop-filter only render in Chromium-based browsers. Safari and Firefox get a frosted blur instead. If you're reading this in one of them, try Chrome to see the real thing.
